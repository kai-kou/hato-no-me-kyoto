# 人物の見た目のリアリティ向上: 外観調査報告

対象: three.js r170 / WebGL2 / ビルドなし / スマホ動作 / 全ジオメトリを起動時に生成 / 人物テクスチャなし。
視点: 地上20 cmのハト視点、望遠・オービット。人物は2〜30 m、昼・夕・街灯・雨上がり。

凡例
- [出典] 取得したページに書かれていた内容。
- [推論] 出典から筆者が導いた内容、または一般的な制作知識。出典には直接書かれていない。
- [未確認] 記憶にはあるが、今回ページを取得して確認できなかった内容。採用前に確認が必要。

## 0. 先に結論

1. この視点では顔より先に靴・裾・足首が見える。足元の形と接地の作り込みが、同じ手間で最も効く。[推論]
2. 不気味さの原因として実証的な支持が最も強いのは「部位ごとのリアルさの不一致」と「リアルな顔の中の非典型な特徴」である。目だけが細かく、顔と手が簡略という現状は、この条件に当てはまる。[出典: Kätsyri 2015, Chattopadhyay & MacDorman 2016]
3. 肌は追加パスなしで「ラップ拡散 + 明暗境界の赤み + 曲率依存」の3点を入れれば足りる。曲率はロフト断面の半径から解析的に与えられるので、テクスチャもfwidthも要らない。[出典 + 推論]
4. 布はCharlieシーン1項と半ラップ拡散で、プラスチック的な見えが大きく減る。GLSLは数行。[出典: Filament]
5. 体型はAISTの実測比に合わせる。男性は7.2頭身、女性は7.0頭身、足長は身長の約14.8%。[出典: AIST 1991-92]

## 1. 肌

### 1.1 ラップ拡散と明暗境界の色づけ

[出典] GPU Gems 第16章 (Green)。Lambert項を次に置き換える。

```glsl
float ndl     = dot(N, L);
float wrapped = max(0.0, (ndl + wrap) / (1.0 + wrap));
// 明暗境界に赤い帯を足す
float scatter = smoothstep(0.0, scatterWidth, wrapped)
              * smoothstep(scatterWidth * 2.0, scatterWidth, wrapped);
vec3 diffuse  = vec3(wrapped) + scatter * scatterColor;
```

出典の例の値: `wrap = 0.2`, `scatterWidth = 0.3`, `scatterColor = (0.15, 0.0, 0.0)`。
https://developer.nvidia.com/gpugems/gpugems/part-iii-materials/chapter-16-real-time-approximations-subsurface-scattering

[出典] Filamentはエネルギーを保つ形として `saturate((NoL + w) / ((1 + w)^2))`、w = 0.5 固定を使う。ラップを使うときは拡散項に NoL を重ねて掛けない。
https://google.github.io/filament/Filament.md.html

[推論] 色チャンネルごとにラップ量を変えると、帯を別に足さなくても境界が赤くなる。出発値は `w = vec3(0.45, 0.25, 0.15)`。赤が最も回り込む。

### 1.2 事前積分スキン (Penner 2011) と解析近似

[出典] Pennerの手法は、拡散の落ち方を肌の拡散プロファイルであらかじめぼかし、NdotLと曲率(1/r)で引く。曲率は次で求める。

```glsl
float curvature = length(fwidth(N)) / length(fwidth(worldPos));
```

微分は三角形内で一定なので、稜線が見える場合は頂点かテクスチャに持たせる、とスライドにある。散乱は暗部で最も目立つので、線形空間のライティングとフィルミックトーンマップが前提とされる。
https://www.slideshare.net/slideshow/penner-preintegrated-skin-rendering-siggraph-2011-advances-in-realtime-rendering-course/13966747

[出典] LUTを使わない解析近似 (Simon's Tech Blog)。赤チャンネルの例:

```glsl
// x は LUT の横軸。記事のサンプルは mad(NdotL, 0.5, 0.5) で引いている
float curve1 = saturate(1.95 * x - 0.96);                 // 曲率が小さい側(硬い境界)
float lin    = saturate(1.75 * x - 0.76);
float quad   = 0.65 * x * x + 0.045;
float curve0 = mix(quad, lin, x * x);                     // 曲率が大きい側(柔らかい境界)
float w      = 1.0 - pow(1.0 - curvature01, 4.0);
float red    = mix(curve0, curve1, w);
```

緑・青は別の係数で、記事のシェーダコードにある。著者は手合わせのフィットと述べている。記事はLUTを正規化した1/rで引き、曲率0..1を半径2..16に対応づけている。
https://simonstechblog.blogspot.com/2015/02/pre-integrated-skin-shading.html

[推論] 注意点が2つある。
- xが0..1に再マップしたNdotLであることは、係数(x = 0.5で値がほぼ0)から見て妥当だが、採用時は原文のコードで確認する。mix の向き(どちらが高曲率側か)も同様に確認する。
- この作品はロフトメッシュなので、断面半径を頂点属性で渡せば曲率が正確に得られる。fwidthもテクスチャも不要。目安の半径: 頭 0.09 m、首 0.055 m、手首 0.027 m、指 0.008 m、鼻 0.012 m、耳 0.004 m。半径が小さいほど赤みの帯が広くなる。

[出典] The Order: 1886 もPenner式の事前積分を採用し、環境光側は曲率で引く帯域調和係数で扱っている。直接光だけでなく環境光も色づける方が一貫する。
https://blog.selfshadow.com/publications/s2013-shading-course/rad/s2013_pbs_rad_notes.pdf

[推論] 環境光の簡易版: 半球アンビエントの法線を使う前に、肌だけ `mix(N, 上向き, 0.15)` で平均化し、赤チャンネルを3〜5%持ち上げる。

### 1.3 逆光の透け (耳・指・鼻翼)

[出典] Barré-Brisebois & Bouchard (GDC 2011)。

```glsl
vec3  ltLight = L + N * distortion;
float ltDot   = pow(saturate(dot(V, -ltLight)), power) * scale;
vec3  lt      = attenuation * (ltDot + ambient) * thickness;   // thickness は「薄いほど大きい」値
color += albedo * lightColor * lt;
```

スライドの比較例: distortion 0 と 0.2、power 4 と 12、scale 1 と 5。powerとambientは素材ごと、scaleは光源ごとに決めるとある。素材別の既定値はスライドにない。
https://www.slideshare.net/slideshow/colin-barrebrisebois-gdc-2011-approximating-translucency-for-a-fast-cheap-and-convincing-subsurfacescattering-look-7170855/7170855

[推論] この作品向けの値: distortion 0.2、power 6、scale 2 (太陽) / 1 (街灯)、ambient 0。thicknessは頂点属性で、耳 1.0、指先・鼻翼 0.5、頬 0.05、それ以外 0。色は `vec3(1.0, 0.25, 0.10)` を掛ける。夕方に太陽を背にした人物の耳が赤く光る効果が得られる。昼の順光ではほぼ見えない。

### 1.4 スペキュラ

[出典] Unrealの肌は粗さの異なる2ローブ(柔らかいローブと締まったローブ)を混ぜる。ドキュメントに数値はない。肌のSpecular既定は0.5。
https://dev.epicgames.com/documentation/en-us/unreal-engine/subsurface-profile-shading-model-in-unreal-engine
https://docs.unrealengine.com/4.26/Resources/Showcases/DigitalHumans

[未確認] 記憶ではUnrealの既定は Roughness0 = 0.75、Roughness1 = 1.3 (基準粗さへの倍率)、LobeMix = 0.85。肌のF0は約0.028 (屈折率1.4)。

[推論] 2〜30 mでは2ローブの差はほぼ見えない。1ローブで粗さ0.45〜0.55、F0 = 0.028で足りる。額・鼻筋・頬骨だけ粗さを0.08下げると、昼に顔の立体が読める。雨上がりは肌の粗さを0.35まで下げる。

### 1.5 かすめ角のフレネル

[推論] ハト視点では脚・腕の輪郭がかすめ角で見える時間が長い。MeshStandardMaterialのSchlick項は既に効いているので、肌専用のリムを足す必要は薄い。足すなら `pow(1.0 - NoV, 4.0) * 0.04 * 空の色` 程度に留める。強いリムはゴム人形に見える。

### 1.6 顔の色のゾーン

[出典] Gurney: 額は明るく黄み、頬と鼻は赤み、目の周りは暗く、首と顎は青みまたは緑み。
https://gurneyjourney.blogspot.com/2017/07/relative-color-temperature-on-skin-tones.html?m=1

[推論] 頂点色での実装値(線形アルベドへの乗算)。
- 額: (1.03, 1.02, 0.96)
- 頬・鼻先・耳: (1.08, 0.94, 0.92)
- 目の周り: 0.88倍
- 顎・首: (0.95, 0.99, 1.00)、男性は顎から頬下にかけてさらに0.93倍
- 手: 指関節と指先を赤み (1.06, 0.95, 0.94)、手のひら側は明るく赤い
- 膝・肘・かかと: 赤み、やや暗い

### 1.7 下から見た顔の陰影

[推論] 地上20 cmから2 m先の顔(高さ1.5 m)を見ると仰角は約33度、10 m先で約7度。近距離では顎の裏、鼻孔、眉の下が見える。頂点色AOを顎下0.6、鼻の下0.7、眼窩0.8、耳の裏0.7で入れる。鼻孔は暗色の頂点色で十分。Uncharted 2の講演は「柔らかくて情報のないマップは平坦に見える」「線形空間のライティングが他の全項目より重要」と述べている。
https://www.advances.realtimerendering.com/s2010/Hable-Uncharted2(SIGGRAPH%202010%20Advanced%20RealTime%20Rendering%20Course).pdf

## 2. 髪 (ストランドもカードも使わない)

### 2.1 Scheuermannの異方性ハイライト

[出典] Scheuermann (ATI, 2004)。

```glsl
vec3 shiftTangent(vec3 T, vec3 N, float shift) { return normalize(T + shift * N); }

float strandSpec(vec3 T, vec3 V, vec3 L, float exponent) {
  vec3  H     = normalize(L + V);
  float dotTH = dot(T, H);
  float sinTH = sqrt(1.0 - dotTH * dotTH);
  float atten = smoothstep(-1.0, 0.0, dotTH);
  return atten * pow(sinTH, exponent);
}

// 拡散: Kajiya-Kay の sin(T,L) は自己影なしだと明るすぎるので使わない
float diff = saturate(mix(0.25, 1.0, dot(N, L)));

vec3 t1 = shiftTangent(T, N, primaryShift   + shiftNoise);  // 毛先側へ
vec3 t2 = shiftTangent(T, N, secondaryShift + shiftNoise);  // 根元側へ
vec3 spec = specColor1 * strandSpec(t1, V, L, exp1)
          + specColor2 * strandSpec(t2, V, L, exp2) * sparkleNoise;
color = (diff * hairColor + spec) * lightColor * ao;
```

Tは根元から毛先向き。正のシフトは根元側へ、負は毛先側へハイライトを動かす。2本目のハイライトはノイズマスクを掛けてきらめかせる。頂点AOで自己影を近似する。出典に指数や色の数値はない。
https://web.engr.oregonstate.edu/~mjb/cs557/Projects/Papers/HairRendering.pdf

[推論] 黒髪向けの出発値: 髪色アルベド (0.020, 0.016, 0.014)、1本目は白っぽく exp 120・shift -0.08、2本目は髪色を明るくした茶で exp 30・shift +0.12。茶髪は2本目を強める。

[推論] テクスチャなしでのノイズ: 頭頂を極とする球座標の方位角 φ を使う。`shiftNoise = (hash(floor(φ * 180.0)) - 0.5) * 0.25` に、流れ方向の低周波ノイズを0.05ほど足す。方位方向に細く、流れ方向に長い縞になり、束に見える。Tは「頭頂から下へ流れる方向」を法線に直交化して作る。

[推論] 望遠で見ると高周波の縞はちらつく。`fwidth(φ * 180.0)` が1を超えたらノイズ振幅を0へ落とす。

### 2.2 輪郭を崩す

[推論] 髪の塊がヘルメットに見える主因は、滑らかな輪郭と、額との境界が1本の線になることである。
- 毛先の輪郭: キャップ下端の頂点を方位角ノイズで5〜15 mm上下させ、厚みも変える。頂点シェーダだけで済む。
- 表面: 束単位(方位角を20〜40分割)で法線を±0.15ラジアン傾ける。
- 生え際: 額側の縁を肌色から髪色へ8〜12 mmの幅でディザ状に遷移させる。

[出典] Unrealのデジタルヒューマンは、生え際でピクセル深度オフセットを使い、髪と頭皮の交差を崩している。考え方として「生え際を硬い線にしない」は共通する。
https://docs.unrealengine.com/4.26/Resources/Showcases/DigitalHumans

### 2.3 Alpha to Coverage のフリンジ

[出典] Golusの手順。MSAA(4倍以上)が必要。アルファを1ピクセル幅に絞る。

```glsl
alpha = (alpha - cutoff) / max(fwidth(alpha), 0.0001) + 0.5;
```

不透明度の段階はMSAAのサンプル数しかない(4倍で5段階)。重なった半透明は積み重ならないので、切り抜きの縁向きである。
https://bgolus.medium.com/anti-aliased-alpha-test-the-esoteric-alpha-to-coverage-8b177335ae4f

[未確認] three.jsでは `material.alphaToCoverage = true` と、MSAAの効いた描画先が必要。公式ドキュメントは今回取得できなかった(4節末の取得不可URLを参照)。

[推論] ソートも追加パスも不要なので、この制約下で髪の縁を柔らかくする唯一の安い手段である。ただしスマホでMSAAを切る設定があるなら、ハッシュ・ディザの切り抜きへ自動で落とす。A2Cは毛先の5〜15 mmと生え際だけに使い、キャップ本体は不透明のままにする。

## 3. 布・靴

### 3.1 シーンモデル

[出典] Filamentの布モデル。フレネル項は使わない。

```glsl
float D_Charlie(float roughness, float NoH) {
  float invAlpha = 1.0 / roughness;
  float cos2h = NoH * NoH;
  float sin2h = max(1.0 - cos2h, 0.0078125);
  return (2.0 + invAlpha) * pow(sin2h, invAlpha * 0.5) / (2.0 * PI);
}
// 可視項込みの分母 (Neubelt & Pettineo)
float V_cloth = 1.0 / (4.0 * (NoL + NoV - NoL * NoV));
vec3  sheen   = sheenColor * D_Charlie(r, NoH) * V_cloth * NoL;
```

指針: シーン色の既定は0.04。デニムや綿などの一般的な布は色をベースカラーに持たせ、シーン色は既定のままか、ベースカラーの輝度にする。ベルベットはベースを黒か暗色にし、色をシーン色に持たせる。革・絹・サテンは標準モデルか異方性モデルで表せる。布の拡散は `saturate((NoL + 0.5) / 2.25)` のラップにできる。
https://google.github.io/filament/Filament.md.html

[出典] Charlie分布の原論文 (Estevez & Kulla 2017)。`D = (2 + 1/r) sin^(1/r)θ / 2π`、rは(0, 1]。rが小さいほどかすめ角に集中し、大きいほど全体に広がる。
https://blog.selfshadow.com/publications/s2017-shading-course/imageworks/s2017_pbs_imageworks_sheen.pdf

[出典] The Order: 1886 はAshikhmin系の逆ガウス分布を使い、同じ分母 `4(n·l + n·v − n·l·n·v)` を採用した。標準のマイクロファセットモデルでは布が説得力を持たなかったと報告している。
https://blog.selfshadow.com/publications/s2013-shading-course/rad/s2013_pbs_rad_notes.pdf

### 3.2 素材ごとの差

出典に素材別の粗さの数値は見つからなかった。以下はすべて [推論] の出発値である。

| 素材 | ベース粗さ | シーン | 備考 |
|---|---|---|---|
| 綿 (シャツ、チノ) | 0.85〜0.95 | 弱 (輝度×0.5)、r 0.6 | 拡散ラップあり |
| デニム | 0.80〜0.90 | 弱、r 0.5 | 膝・腿前・尻の色落ち、縫い目の明色 |
| ウール (コート、ニット) | 0.95〜1.0 | 強 (輝度×1.0)、r 0.8 | 輪郭が白っぽく浮く |
| ナイロン (ジョガー、ダウン) | 0.35〜0.50 | なし | 通常のGGX。皺のハイライトが鋭い |
| 絹・化繊の着物 | 0.35〜0.45 | なし | 縦糸方向の弱い異方性。帯は粗さ0.3 |
| 革靴 | 0.25〜0.40 | なし | つま先だけ粗さを下げる |
| スニーカーのメッシュ | 0.85 | 弱 | ミッドソールは粗さ0.6の白 |
| ゴム底 | 0.75〜0.85 | なし | 暗色。雨上がりは0.3 |

### 3.3 2〜5 mで見える布の模様

[推論] 縦1080ピクセル、垂直画角60度と仮定すると、2 m先の1ピクセルは約2.1 mm、5 m先は約5.3 mm。織り目(0.3〜1 mm)は解像しない。描くとモアレになるので描かない。見えるのは次の3〜30 mm以上の要素である。
- 縫い目: ズボン脇、内股、裾の折り返し(幅10〜20 mm)、ポケット口、前立て。頂点色で±8%の明暗線。
- 色むら: デニムの縦落ちと膝の色落ち、綿の皺の山の退色。低周波ノイズで±5%。
- 布の厚み: 裾・袖口・襟に1.5〜3 mmの縁。下から見るので裾の内側(暗い)が見える。

望遠カメラでは1ピクセルがさらに小さくなる。織り目を入れるなら `fwidth` で画面上の周期が3ピクセル以上のときだけ出す。

### 3.4 皺と折り目の位置

[出典] 折り目の型と位置 (Bridgman系の分類の解説)。
- パイプ: 支点から重力でまっすぐ落ちる筒状の皺。
- ダイパー: 2点で吊られた布のたるみ。
- スパイラル: 腕など筒のまわりに巻きつく皺。袖や筒状の服。
- ジグザグ: 交互に折れ曲がる皺。ズボンの膝の前後、特にジーンズ。
- ハーフロック: 曲がり角のたまり。肘と膝。中心に深いポケット状のくぼみ。
- ドロップ: 支点から落ちて向きを変える皺。
- イナート: 面の上に崩れた布。
https://papillary.blogspot.com/2016/06/drawing-clothing-and-folds.html
https://www.proko.com/lesson/a-review-of-the-7-folds (皺は張力点・重力・動きで生じるという整理。本文は有料)

[推論] 配置の規則。
- 皺は張力点(肩先、肘、尻、膝、股)から放射し、関節の曲がる内側に圧縮皺がたまる。
- 膝: 裏に横方向のジグザグ3〜5本、表は伸びて滑らか。振幅は関節角に比例させる。立位でも1〜2本残す。
- 股: 股の一点から腿の付け根へ放射状に4〜6本(座位で強く、歩行では後ろ脚側に出る)。
- 肘: 内側にハーフロック、外側は張る。上腕にスパイラルが1〜2本。
- 足首: 裾が甲に当たって1〜3段たまる(ブレイク)。細身のズボンは段が多く、太いズボンは1段で前に折れる。この視点で最も近くに見える皺である。
- 上着の背: 肩甲骨から脇へ斜めの引き皺。腰でたるむ。
- 着物: 皺は少なく、縦のパイプが主。おはしょり、帯の下の横皺、歩行時に前裾が割れる八の字。裾は足首で揺れ、裏地(八掛)が下から見える。
- 厚い布ほど皺は少なく太い。ウールコートは波長40〜80 mm、綿シャツは10〜25 mm、ナイロンは5〜15 mmで鋭い。

実装は頂点変位(振幅2〜6 mm)と法線の傾きで行う。位置は骨のローカル座標で決め、振幅は関節角で駆動する。

### 3.5 靴と靴底

### 4.2 手続き生成の人物がマネキンに見える典型的な誤り

## 5. 知覚

### 5.1 不気味の谷

[出典] Kätsyri ら (2015) の実証研究レビュー(17研究)。
- 「人間らしさを上げれば必ず谷が出る」という素朴な仮説は、8研究中1研究しか支持しなかった。多くは人間らしさとともに好感が単調に上がった。
- 「リアルさの不一致」仮説は4研究中4研究が支持した。例は、人間らしい顔に人工的な目を載せた場合。
- 「非典型な特徴」仮説は4研究中3研究が支持した。例は、リアルな顔の著しく大きい目。
- 動きが谷を深くするという予測は支持されなかった。カテゴリの曖昧さも単独では説明にならなかった。
- 結論: 谷は特定の条件、すなわち人工的特徴と人間的特徴の不一致、または人間らしい顔の非典型な特徴があるときにだけ生じる。
https://www.frontiersin.org/articles/10.3389/fpsyg.2015.00390/full

[出典] Chattopadhyay & MacDorman (2016)。目・まつ毛・口と、肌・鼻・眉とでリアルさの水準を変えると不気味さが増した。この効果は人と動物で生じ、物体では生じなかった。不一致は見慣れなさを通じて不気味さを増す。
https://core.ac.uk/download/46964535.pdf

[出典] Zell ら (2015)。形の様式化はリアルさの知覚と表情の強さを最も左右し、素材の様式化は魅力を最も左右した。リアルさだけでは魅力も不気味さも予測できなかった。
https://ls7-gv.cs.tu-dortmund.de/publications/2015-stylize.page/

[推論] この作品への含意。
- 現状は、目(強膜・虹彩・瞳孔・ハイライト・まつ毛)が細かく、鼻は小さな造形、口・耳・手は簡略である。これは「目だけリアル」という不一致の条件そのものである。2〜3 mで人工的に見えるという作者の観察と合う。
- 対策は2方向ある。目の情報量を下げて他に合わせるか、他(まぶたの厚み、口の線、耳、顎下の影)を上げて目に合わせるか。安いのは前者で、効果が確実なのも前者である。
- 具体策: 目のハイライトとまつ毛を距離で消す。上まぶたの影を虹彩の上1/3に落とす。白目を純白にせず (0.75, 0.72, 0.70) 程度にする。白目が明るすぎる目は、遠目に「見開いた目」として読まれ、非典型な特徴になる。
- 2 mで虹彩(直径約12 mm)は約6ピクセル、5 mで約2ピクセルである(3.3節の仮定)。5 m以遠ではまつ毛もハイライトもサブピクセルで、ちらつきだけが残る。距離で目の細部を消すのは理にかなう。
- 被写界深度のぼかしや距離が谷を弱めるという直接の実験結果は、今回の調査では見つからなかった。不一致仮説からは「細部が見えなければ不一致も見えない」と推論できるが、これは推論である。

取得不可: MacDorman ら (2009) "Too real for comfort" と Seyama & Nagayama (2007) は本文を取得できなかった。[未確認] 記憶では、前者は肌の質感のリアルさと顔の比率の不一致、後者はリアルな顔での目の拡大が不気味さを生むと報告している。

### 5.2 群衆で見られる部位と、効く多様性

[出典] McDonnell ら (2009) "Eye-catching Crowds"。視線計測で、頭と上半身が最初の注視の大半を集め、最も長く見られた。頭の装身具、上半身のテクスチャ、顔のテクスチャは多様性の演出に同程度に有効で、顔の形状の変更はそれより効果が低かった。目立つ部位だけの色変更は、全身の色変更と同じ効果があった。
https://edepositireland.ie/handle/2262/31386

[出典] McDonnell ら (2008) "Clone Attack!"。外見のクローンは動きのクローンよりはるかに見つかりやすい。色の変化、向きのランダム化、動きがクローンを隠す。
https://research.gold.ac.uk/id/eprint/15203

[出典] Vyas & O'Sullivan (2024)。12体の群衆で、体型の種類数はクローン検出に有意な影響がなく、動きの種類数は小さいが有意な影響があった。参加者が手がかりに挙げたのは腕と手の動き、速度、頭の動き、肩の動きの順。先行研究として、3種類の動きを位相をずらして配れば完全に多様と知覚されたという報告を引いている。
https://arxiv.org/html/2412.16151v1

[出典] 群衆表現のLOD比較 (2025)。近距離・高詳細ではメッシュが明確に優位で、距離が離れると安価な表現との差が縮まる。
https://arxiv.org/html/2510.20558

[推論] この作品への含意。
- 上記の視線研究は立った人の目の高さの視点である。地上20 cmの視点での注視部位を調べた研究は見つからなかった。近い人物では画面に入るのが足元だけなので、靴・裾・脚の多様性(靴の種類、裾丈、ズボンの太さと色)を頭・上半身と同等に扱うべきである。
- 36人なら、色の変化は上半身と頭(髪型、帽子、マスク、眼鏡、イヤホン、鞄)に集中させる。顔の形の作り分けは優先度が低い。
- 体型の種類を増やすより、歩行の位相・速度・腕の振り幅をずらす方が効く。

## 7. この制約下で試す価値が低いもの

| 項目 | 理由 |
|---|---|
| スクリーン空間SSS、テクスチャ空間拡散 | 追加パスとぼかしが必要。Hableも「首の後ろに専用のSSSパスは費用に見合わない」と述べている。事前積分で代替できる |
| ストランド髪、ヘアカード | ソートと多パス描画が必要(Scheuermannは3パス)。スマホで36人には重い。カードにはアルファテクスチャが要る |
| 肌の2ローブスペキュラ | 2 m以遠では1ローブとの差が見えない [推論]。命令数だけ増える |
| 毛穴、織り目などの微細模様 | 2 mで1ピクセル約2 mm。解像せず、エイリアシングだけが出る [推論] |
| 眼球の屈折、虹彩の視差、コースティクス | 目をさらにリアルにすると不一致が広がる。5.1の知見に反する方向である |
| 全員をMeshPhysicalMaterialにする | [未確認] シーン、クリアコート等の分岐で標準マテリアルよりシェーダが重い。必要なCharlie 1項だけを既存フックに足す方が安い |
| 影の半影での散乱 (Penner) | 広い半影と専用の小さなシャドウマップが要る。距離が遠く見えない |
| 布のシミュレーション | 実行時負荷が大きい。関節角で駆動する皺と、裾・袖の簡単な遅れで代替できる |
| 指の完全な骨格 (片手15本以上) | 骨数がほぼ倍になる。親指の分離と指の溝の描き込みで2 m以遠は足りる |
| 表情のブレンドシェイプ、リップシンク | 仰角の浅い遠景でほぼ見えない。まばたきと視線の向きだけで足りる |
| 顔の形状の個人差の作り込み | McDonnell 2009で、顔形状の変更は装身具やテクスチャより効果が低い |
| 体型の種類を大幅に増やす | Vyas & O'Sullivan 2024で、体型の種類数はクローン検出に有意な影響がなかった |
