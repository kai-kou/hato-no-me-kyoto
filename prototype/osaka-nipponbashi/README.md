# ハト視点シミュレーター 大阪・日本橋（試作）

「鳩の目、京都。」の前身です。大阪・日本橋の街並みを、測量データを使わずにコードだけで組み立てています。この試作のあと、「PLATEAU で最もリアリティを出せる地域に場所を移す」という指示から京都版を作りました。

```sh
python3 -m http.server 8001 --directory prototype/osaka-nipponbashi
# http://localhost:8001/ を開く
```

| ファイル | 内容 |
| --- | --- |
| `index.html`、`game.js` | 試作の本体 |
| `three.core.js`、`three.module.js` | three.js r187（MIT License） |

建物の形と見た目は手続き生成です。通りと施設の名前は、目印として実在のものを使っています。配置は実際の街区をもとにした概略で、測量データは使っていません。

京都版で直した誤りが、ここにはそのまま残っています。たとえばハトの視野を 330° としていますが、文献を確認した値は約 320° です。
