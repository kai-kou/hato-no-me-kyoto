# 静止画と動画

すべて作品の画面をそのまま撮ったものです。撮影はヘッドレス Chrome のソフトウェア描画で行いました。撮影方法は [tools/README.md](../tools/README.md) にあります。

国土交通省 Project PLATEAU の 3D 都市モデル（京都市、2025 年度）と、国土地理院の地理院タイルを加工して作成した画面です。出典と利用条件は [NOTICE.md](../NOTICE.md) にあります。

## 動画（`video/`、`clips/`）

`video/hato_kyoto_x.mp4` は X への投稿用にまとめた動画です。1280×720、30 fps、音声なし。`tools/xvideo.py` が `clips/` のクリップに字幕を重ねて作ります。

ビルドの番号は公開した版の通し番号で、`app/` にあるのは v27 です。v24 では、ハトの羽を重なり合う羽として描き直し、開いたときに最初に出る紹介ページを足しました。v25 では、尾羽を 1 枚ずつ先を丸め、中央を高くして重ねました。v26 では、夜の明かりとねぐら、飛んでいるハトの翼と胴、LOD2 の建物の屋根を直しました。v27 では、水飲みと水浴びの場所になる水際の判定を直しました。夜の静止画（v26）と夜のクリップ（v27）は、いまの版で撮り直したものです。v11 で録画した以前の夜のクリップは、壁や看板が実際より強く光っていたので外しました。そのほかの静止画とクリップは v21 までのもので、ハトの羽と尾、飛んでいる姿が公開中の版と違います。紹介ページの画像と動画（`app/lp/`）は、ここにある静止画とクリップ、v24 で撮り直した操作画面から作っています。v22 は v21 と見た目が同じで、情報パネルの表記と壁のシェーダーの計算量だけが違います。v23 では、建物の足元で抜けていた地面をふさぎ、建物まわりの地面を描き直しました。v22 までの素材には、路地の壁際に白い帯が写っているものがあります。v12 のクリップは人を作り直す前のビルドで撮ったもので、人が写らないカットだけを使っています。
