## 素材

動画は、[media/clips](../media/clips) のクリップ、公開中の版を撮った画面、説明用のカードから作っています。夜の祇園白川の場面は v27 で撮り直しました。そのほかのクリップは v12〜v21 の録画で、ハトの羽と尾の描き方が公開中の版と違います。スライドの画面は v24 で撮ったもので、夜の画像だけ v26 で撮り直しています。
